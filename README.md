# Overview
This project investigates how physiological signals collected from wearable devices relate to stress levels in healthcare workers during the COVID-19 pandemic. Using biometric data from nurses in hospital environments, the analysis explores whether signals such as electrodermal activity (EDA), heart rate (HR), and body temperature (TEMP) can be used to better understand and classify stress.

The project was completed in R as part of a statistical modeling and data analysis study focused on interpreting physiological stress patterns through both classical statistical methods and machine learning approaches.

# Dataset

Dataset: Nurse Stress Prediction Wearable Sensors

Source:
https://www.kaggle.com/datasets/priyankraval/nurse-stress-prediction-wearable-sensors

The dataset contains approximately 11.5 million observations collected from nurses working during the peak of the COVID-19 outbreak in the United States. The data includes physiological measurements such as electrodermal activity (EDA), heart rate (HR), body temperature (TEMP), and labeled stress levels used for statistical analysis and predictive modeling.

# Methods Used
Exploratory Data Analysis, Correlation Analysis, One-Way ANOVA, Tukey Post-Hoc Testing, Simple Linear Regression, Multinomial Logistic Regression, Class Imbalance Analysis

# Technical Focus
A major focus of this project was understanding the difference between statistical significance, predictive performance, and meaningful model evaluation. The project emphasizes interpretation over raw accuracy, particularly in the context of imbalanced healthcare datasets.
